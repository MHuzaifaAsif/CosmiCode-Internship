# Software Testing / QA Internship - Progress Tracker

This repository documents my progress through a 6-week Software Testing and QA internship program. Each week involves a set of practical tasks designed to build knowledge in manual and automated testing.

---

## ✅ Week 1: Introduction to Software Testing

**Objective**: Understand basic concepts, types of testing, and the Software Development Life Cycle (SDLC).

### ✅ Tasks Completed:
- Wrote a document explaining what software testing is, its purpose, and types (manual vs. automated).
- Explained SDLC models (Waterfall, Agile, V-Model) and how QA fits into each.
- Defined different levels of testing (Unit, Integration, System, Acceptance) with relevant examples.
- Created a simple test plan outline for a basic login application.
- Wrote 5 detailed test cases for a login form covering various scenarios.

-------------------------------------------------------------------------------------------------------------

## ✅ Week 2: Manual Testing

- **Test Cases**: Wrote detailed positive and negative test cases for a user registration form including field validation, empty inputs, and format checks.
- **Bug Reporting**: Created a reusable bug report template and logged 5 sample bugs for [OrangeHRM](https://opensource-demo.orangehrmlive.com), covering login, UI, and validation issues.
- **Severity vs Priority**: Documented the difference with examples:
  - *High severity, low priority*: Crash in rarely used feature.
  - *Low severity, high priority*: Typo in the homepage title.
- **Functional Testing**: Performed on OrangeHRM; tested login, forgot password, and dashboard functionalities. Logged issues in test report.
- **Test Report**: Summarized test execution results, status of test cases (pass/fail), and bug severity/priority.

--------------------------------------------------------------------------------------------------------------

## ✅ Week 3: Web & Mobile App Testing

- **Cross-Browser Testing** performed on [OrangeHRM](https://opensource-demo.orangehrmlive.com) using Chrome, Firefox, and Edge. Minor UI inconsistencies observed in Firefox.
- **Mobile App Testing** done on **Daraz App (Android)**. Documented 5 bugs related to UI overlap, input validation, and real-time updates.
- **Explored Remote Testing Tools**: Compared BrowserStack and Sauce Labs for real device/cloud-based testing and CI/CD support.
- **Responsive Testing**: Checked OrangeHRM on laptop, tablet, and mobile view using Chrome DevTools. UI mostly responsive with slight compression on tablet.
- **Mobile vs Web Testing**: Highlighted differences in gesture handling, device compatibility, and usability concerns.
